## Der schnelle Ablauf

```
Firebase Studio (alt)  →  GitHub + Claude Code (neu)
      Code+Build+Host        Lager + KI-Schreiben + Firebase hostet weiter
```

1. **Schreiben:** Claude Code / GitHub Antigravity (KI schreibt, ihr prüft)
2. **Speichern:** GitHub (`git push`) — Versionen sind automatisch sicher
3. **Testen:** `dev.paulikreisch.de`
4. **Live:** `paulikreisch.de` (Firebase App Hosting)
5. **Versionieren:** bei Meilensteinen ein `vX.Y.Z`-Tag

## Eure Tools auf einen Blick

- **GitHub** — Code-Lager + Versionen (kostenlos)
- **Claude Code** — KI, die lokal Code schreibt (Philipp)
- **GitHub Antigravity** — KI-IDE im Browser, wie Firebase Studio (Max)
- **OpenRouter** — Marktplatz für KI-Modelle (Claude, GPT, Gemini, …)
- **Firebase** — App Hosting + Firestore (DB) + Storage (Bilder) — **bleibt**
